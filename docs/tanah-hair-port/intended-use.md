# Intended use boundary

TANAH-HAIR supports administrative workflow, standardized capture guidance, clinician-authored planning, procedure documentation and longitudinal follow-up.

It is not intended to autonomously diagnose alopecia, determine candidacy, select FUE/FUT/DHI, prescribe medication, calculate a safe harvest limit, predict graft survival, or guarantee a cosmetic result.

The Gemini integration is a disabled-by-default, non-clinical visualization sandbox. It accepts structured synthetic concept inputs only in this release. Generated assets are permanently labeled as hypothetical and cannot be treated as postoperative evidence or marketing results.
